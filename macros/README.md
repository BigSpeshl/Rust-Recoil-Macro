Recoil macros — AutoHotkey (основное)

Файлы:
- recoil.ahk — основной AutoHotkey-скрипт с GUI

Требования:
- AutoHotkey v1.1+ (Windows)

Запуск:
1. Скопируй папку "macros" на Windows.
2. Установи AutoHotkey (https://www.autohotkey.com/).
3. Дважды кликни recoil.ahk.

Краткое руководство по использованию:
- Горячая клавиша F8 — включить/выключить макрос.
- В GUI: настрой Sensitivity (слайдер) и FOV, выбери оружие и модификатор прицела.
- Кнопки Save/Load позволяют сохранять настройки в profiles/*.ini.
- Нажми и удерживай ЛКМ для работы компенсации отдачи при включенном состоянии.

Важное предупреждение:
Использование макросов для автоматизации отдачи в rust нарушает правила и может привести к блокировке аккаунта. Использовать только в оффлайн-режимах или для разработки/тестирования.
