# 🎯 Rust Recoil Macro

> Открытый проект макроса для автоматизации компенсации отдачи в Rust, полностью написанный на Python.

## 📌 О проекте

Этот репозиторий содержит макрос для **Rust**, предназначенный для автоматизации компенсации отдачи оружия и настройки управления стрельбой.

Проект имеет **полностью открытый исходный код**. Каждый желающий может изучить реализацию, изменить существующий код, исправить ошибки, добавить новые функции или полностью переработать отдельные части проекта.

## 🐍 Технологии

* **Python** — основная логика проекта.
* **AutoHotkey** — файл макроса.
* **Open Source** — исходный код полностью открыт для сообщества.

## ⚙️ Возможности

* 🎯 Автоматизация компенсации отдачи.
* 🔧 Настройка параметров макроса.
* 🖥️ Работа на Windows.
* 🐍 Открытая реализация.
* 🧩 Возможность расширения функциональности сообществом.
