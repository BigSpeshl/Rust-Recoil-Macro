# 🎯 Rust Recoil Macro

**Панель управления макросом компенсации отдачи на AutoHotkey.** Скрипт открывает GUI, в котором можно выбрать оружие и параметры, а затем применяет заданный макрос движения мыши при удержании левой кнопки.

> ⚠️ **Внимание:** макрос может нарушать правила Rust и привести к бан. Используйте проект только в тестах, для разработки или тестирования.

## ✨ Возможности  

- Макросы для 18 видов оружия.
- GUI для выбора оружия, настройки чувствительности и модификатора прицела.
- Включение и выключение клавишей **F6**.
- Быстрый выбор первых девяти видов оружия клавишами **1–9**.
- Сохранение и загрузка настроек и макросов в профилях **INI**.
- Экспериментальный режим **Learn** для копинсации макроса по движению курсора.

## ⚙️ Как работает скрипт

`recoil.ahk` написан для **AutoHotkey v1.1** и работает в Windows. При запуске он создаёт графический интерфейс и регистрирует горячие клавиши. Когда макрос включён и удерживается **ЛКМ**, скрипт циклически проходит макрос выбранного оружия и отправляет относительные смещения мыши через Windows API. Интервал между шагами задаётся в макросе.

Большинство профилей используют вертикальные координаты, а макрос AK содержит пары горизонтального и вертикального смещений. Сила движения масштабируется настройкой **Sensitivity** и выбранным модификатором прицела.

Макросы и интервалы можно менять в начале `recoil.ahk`. Настройки профиля сохраняются в `profiles/*.ini` рядом со скриптом. Режим **Learn** экспериментальный: проверяйте полученные значения и корректируйте их при необходимости.

> **Примечание:** поле **FOV** доступно в GUI и сохраняется в профиле, но в текущей версии не участвует в расчёте движения мыши.

## 🚀 Запуск

1. Установите [AutoHotkey v1.1](https://www.autohotkey.com/) на Windows.
2. Запустите `recoil.ahk` двойным щелчком.
3. Выберите оружие и настройте параметры в окне программы.
4. Нажмите **F6**, чтобы включить макрос.
5. Удерживайте **ЛКМ**, чтобы применить паттерн. Нажмите **F6** ещё раз для выключения.

## 🎮 Управление

| Действие | Управление |
| --- | --- |
| Включить или выключить макрос | `F6` или кнопка в GUI |
| Выбрать оружие | Кнопка в GUI или клавиши `1–9` |
| Изменить чувствительность | Слайдер **Sensitivity** |
| Выбрать модификатор прицела | Список **Scope modifier** |
| Сохранить или загрузить профиль | **Save profile** / **Load profile** |
| Переключить режим обучения | **Learn** |
| Применить паттерн | Удерживать **ЛКМ**, когда макрос включён |
